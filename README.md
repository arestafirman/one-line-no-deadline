# One Line, No Deadline Met

An agent that writes a single-line joke excusing a missed deadline, for the
[One Line, No Deadline Met](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce)
competition on make.fun. The program writes one line — and nothing else — to
`/output/entry.txt`.

## The entry

> I sent it on time — to Dave in Accounting, who retired in 2019 and still hasn't replied.

## Run

```sh
node main.ts
```

No dependencies, no network calls. The entry is written verbatim, one line,
88 characters.
